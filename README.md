# Nafeel Ahamed — Portfolio

A responsive personal portfolio. Built with plain HTML, CSS, and JavaScript; there is no build step or package installation required.

## Deployment

- **Live site:** [nafeel-portfolio-one.vercel.app](https://nafeel-portfolio-one.vercel.app)
- **Source:** [github.com/nafeelahd/nafeel-portfolio](https://github.com/nafeelahd/nafeel-portfolio)
- The Vercel project is connected to this GitHub repository. Push changes to `main` to trigger a production deployment.

## Run locally

1. Open this folder in VS Code.
2. Open `index.html` directly in a browser, or use the Live Server extension and select **Open with Live Server**.

Google Fonts are loaded over the internet. The site uses system font fallbacks if they are unavailable.

## Portfolio sections

- **About** — background, education, and design experience.
- **Selected work** — brand and marketing visuals, plus the [Zoviq GitHub repository](https://github.com/nafeelahd/zoviq).
- **Toolkit** — frontend, backend, database, design, and language skills.
- **Journey** — education and work experience.
- **Contact** — email, LinkedIn, and GitHub.
- **Download CV** — a direct download link to the included PDF.

The hero is focused on software engineering. Scroll-reveal animations replay as sections enter and leave the viewport, and respect the operating system's reduced-motion preference.

## Project files

- `index.html` — page structure, content, and navigation.
- `style.css` — responsive layout, visual design, and animations.
- `script.js` — accessible, replayable scroll-reveal animations.
- `assets/nafeel-ahamed-cv.pdf` — downloadable CV.
- `assets/nafeel-portrait-watch.webp` — transparent portrait used in the hero.
- `assets/nafeel-portrait-cutout.webp` — full transparent portrait cutout.
